# Create: Kinetic Lift

Create: Kinetic Lift is a NeoForge 1.21.1 addon for [Sable](https://modrinth.com/mod/sable) and [Create](https://modrinth.com/mod/create) that introduces modern aircraft components and systems. Support for
**Xbox controllers**, the *Thrustmaster T-Flight HOTAS*, and the *WINCTRL AIRLINE CONTROLS* is also planned.

## Features

- **Jet Engines:** Produce over 14,500 pN of thrust for high-speed travel.
- **Sidestick Seat:** Provides full control over the aircraft's various components.
- **Computer Cable:** Connects aircraft components to form a complete avionics system.
- And **more** to come soon!

## Dependencies

- [Sable](https://modrinth.com/mod/sable)
- [Create](https://modrinth.com/mod/create)
